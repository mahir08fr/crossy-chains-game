# Gameplay screenshots

[Back to the project](../../README.md)

Captured from the running public source copy in Safari on October 25, 2026. All images are 1920 × 1080 lossless PNGs. The pointer was parked in browser chrome outside the capture region before each still. Browser chrome was cropped out, and the original Retina captures were downsampled consistently. No gameplay content was added, painted over or composited.

| File | Context |
| --- | --- |
| `main-menu.png` | Four-character online setup menu before creating a room |
| `chained-gameplay.png` | Two-player generated-world movement beside live traffic |
| `four-player.png` | Four-seat authoritative room on loopback, with one browser and three local SDK-controlled seats |
| `river.png` | Original river course with a swimming goose, water-exposure indicator and physical chain |
| `railway.png` | Original railway course during a passing freight train |

Each screenshot was individually inspected for cursor visibility, loading failures, debug panels, popups and sensitive room information. These captures show implemented gameplay and presentation; they do not establish real four-person coordination, device compatibility, public-hosting capacity or endurance acceptance.
